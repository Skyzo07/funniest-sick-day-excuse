One line, under 200 characters, that someone could send to call in sick — the funniest excuse in one breath.

> Can't come in — I sneezed so hard my back filed for workers' comp.

The line is written verbatim by `main.ts` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with a runtime guard that fails loudly unless it is a single unpadded line of 1–200 characters. No network, no clock, no randomness.
